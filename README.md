# Michel Silveira — Portfolio

**Live:** [michelgss.github.io/portfolio](https://michelgss.github.io/portfolio/)

Personal portfolio for Michel Silveira, Technical Writer with a Full Stack background. Built with a "Terminal Meets Editorial" aesthetic — deep black, crisp white, monospace details, and fluid animations.

## Features

- Typing effect hero with animated cursor
- Scroll-triggered reveals with stagger (Framer Motion)
- Vertical timeline for experience entries
- Skill badges with 3D tilt + glow on hover
- Custom cursor with smooth lag
- Grain overlay texture
- Scroll progress bar
- Magnetic CTA buttons
- Fully responsive (mobile-first)

## Local development

```bash
npm install
npm run dev
```

## Deploy

```bash
npm run deploy
```

Builds with Vite and publishes the `dist/` folder to the `gh-pages` branch.
